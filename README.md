
# Student Grade Tracker

## Internship
CodeAlpha Java Programming Internship

## Project Description
Student Grade Tracker is a Java console-based application
used to manage student names and grades.

## Features
- Add student details
- Display all student records
- Calculate average grade
- Find highest grade
- Find lowest grade
- Search student by name
- Validate student grades

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- BufferedReader
- VS Code

## How to Run

Compile:
javac StudentGradeTracker.java

Run:
java StudentGradeTracker
